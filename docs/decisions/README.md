# Architecture Decision Records

Meaningful architectural decisions are recorded here, one file per decision,
numbered sequentially (`NNN-title.md`).

Each record follows this template:

```markdown
# NNN. Title

## Context
What situation forced a decision?

## Decision
What did we decide?

## Reason
Why this option?

## Alternatives considered
What else was evaluated and why it was rejected.

## Consequences
Trade-offs, follow-ups, and things this constrains.
```

Do not re-debate a decided choice unless new information requires it.
